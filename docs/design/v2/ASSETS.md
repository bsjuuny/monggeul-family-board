# 몽글 패밀리 보드 v2 그림 자산

모든 자산은 내장 이미지 생성 기능으로 새로 만들었으며 외부 유료 API 키를 사용하지 않았다. 생성 후 파일 규격만 무손실 PNG 컨테이너로 정리했고, 풍경 3종은 같은 크기와 동일한 창밖 구도로 맞췄다.

| 파일 | 실제 크기 | 알파 | 용도 |
|---|---:|---|---|
| `public/art/board/scene-morning.png` | 2400×1000 | 없음 | 아침 창밖 풍경. 해 뜨는 하늘, 언덕, 작은 성, 벚꽃, 넓은 창턱 |
| `public/art/board/scene-afternoon.png` | 2400×1000 | 없음 | 오후 창밖 풍경. 아침 장면과 같은 구도, 맑은 하늘·민트 언덕 |
| `public/art/board/scene-evening.png` | 2400×1000 | 없음 | 저녁 창밖 풍경. 같은 구도, 피치·라벤더 노을과 작은 별 |
| `public/art/board/commute-path.png` | 1400×1000 | 있음 | 집에서 어린이집까지 이어지는 꽃길. 등하원 카드 장식 레이어 |
| `public/art/board/paper-texture.png` | 512×512 | 없음 | 전체 배경과 카드에 3–5% 강도로 올리는 반복형 크림 종이 질감 |
| `public/art/board/card-weather.png` | 1400×600 | 있음 | 날씨 카드 아래쪽에 은은하게 깔리는 낮은 언덕·구름·옅은 눈의 작은 나무 장식 |
| `public/art/board/card-notice.png` | 700×700 | 있음 | 공지 카드 오른쪽 아래에 놓이는 꽃 덤불과 하트 봉인 편지 장식 |
| `public/art/board/card-prep.png` | 700×700 | 있음 | 준비물 카드 오른쪽 아래에 놓이는 노란 모자·물병·작은 가방과 풀꽃 장식 |

## 생성 방식과 프롬프트 요약

### `scene-morning.png`

- 방식: 내장 이미지 생성, 신규 일러스트.
- 핵심 프롬프트: 따뜻한 아침 수채화 동화책, 가로 2.4:1 창문, 겹친 언덕, 오른쪽 먼 성, 해 뜨는 하늘, 오른쪽 벚꽃, 아래 18%의 넓고 비어 있는 창턱.
- 금지: 글자, 숫자, UI, 사람, 동물, 캐릭터, 얼굴, 로고, 워터마크.

### `scene-afternoon.png`

- 방식: 아침 원화의 조명·시간대 편집.
- 핵심 프롬프트: 창틀·커튼·창턱·언덕·성·벚꽃·카메라 위치를 유지하고 맑은 오후의 하늘색·민트 팔레트로만 변경.
- 금지: 구도 변경, 새 사물, 글자, UI, 캐릭터.

### `scene-evening.png`

- 방식: 아침 원화의 조명·시간대 편집.
- 핵심 프롬프트: 같은 구도를 유지하고 피치 노을에서 라벤더 초저녁으로 이어지는 하늘, 위쪽에 작은 별 몇 개만 추가.
- 금지: 달, 구도 변경, 새 전경 사물, 글자, UI, 캐릭터.

### `commute-path.png`

- 방식: 내장 이미지 생성, 투명 배경 신규 일러스트.
- 핵심 프롬프트: 왼쪽 아래 작은 집에서 오른쪽 위 어린이집까지 이어지는 크림색 S자 꽃길, 둥근 수채화 동화책 형태, 넓은 투명 여백.
- 금지: 간판 글자, 숫자, 사람, 동물, 차량, 캐릭터, UI.

### `paper-texture.png`

- 방식: 내장 이미지 생성으로 저대비 크림 수채화 종이를 만든 뒤 512×512로 규격화. 256px 원본 타일을 좌우·상하 미러링해 네 변이 이어지게 구성하고 `#FFF8EA` 위에 불투명 합성.
- 핵심 프롬프트: 따뜻한 크림, 매우 옅은 종이 섬유와 펄프, 중심광·테두리·접힘·얼룩 없이 균일하고 반복 가능한 질감.
- 권장 사용: pseudo-element에 `background-repeat: repeat; opacity: .04; pointer-events: none;`.

### `card-weather.png`

- 방식: 기존 보드 레퍼런스와 `scene-morning.webp`, `commute-path.webp`를 화풍·색감 참고 이미지로 사용한 내장 이미지 생성. 투명 PNG로 생성한 뒤 1400×600 투명 캔버스에 맞추고 장식을 아래 45% 안에 정렬했다.
- 핵심 프롬프트: 낮은 세이지색 언덕, 작은 침엽수 몇 그루, 솔잎 끝의 아주 옅은 눈, 흐린 구름 한두 개, 낮은 채도와 부드럽게 사라지는 수채화 가장자리.
- 금지: 강한 겨울색, 눈 덮인 지면, 글자, 숫자, UI, 사람, 동물, 얼굴, 캐릭터, 불투명 배경.

### `card-notice.png`

- 방식: 같은 레퍼런스 3종을 화풍·색감 기준으로 사용한 내장 이미지 생성. 투명 PNG로 생성한 뒤 700×700 캔버스의 오른쪽 아래 1/3 안에 배치했다.
- 핵심 프롬프트: 작은 저채도 꽃 덤불, 크림색 편지 한 장, 작은 하트 봉인, 밝은 종이결 수채화와 넓은 투명 여백.
- 금지: 글자, 숫자, UI, 사람, 동물, 얼굴, 캐릭터, 고채도, 불투명 배경.

### `card-prep.png`

- 방식: 같은 레퍼런스 3종을 화풍·색감 기준으로 사용한 내장 이미지 생성. 투명 PNG로 생성한 뒤 700×700 캔버스의 오른쪽 아래 1/3 안에 배치했다.
- 핵심 프롬프트: 작은 버터색 모자, 연한 물병, 작은 살구색 가방, 풀밭과 몇 송이 꽃, 밝고 낮은 대비의 수채화.
- 금지: 글자, 숫자, UI, 로고, 사람, 동물, 얼굴, 캐릭터, 고채도, 불투명 배경.

## 사용 주의

- 풍경에 캐릭터를 다시 그리지 않는다. `src/ui/characters/*.tsx` SVG를 별도 레이어로 올린다.
- 풍경의 아래 창턱은 캐릭터 좌석이므로 텍스트를 두지 않는다.
- 본문을 풍경 위에 직접 올리지 않는다. 반드시 명세의 불투명 카드 또는 밝은 스크림을 사용한다.
- 세 풍경은 `background-size: cover; background-position: center 52%`를 공통 적용한다.
- 종이 질감은 원본 색을 덮을 정도로 진하게 쓰지 않는다. 화면 기준 최대 5% 강도다.
