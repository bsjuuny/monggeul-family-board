## 3. 구현한 것(공식 수단이 생기면 바로 연결)

- `tablet_server/kidsnote.py`
  - `NoticeSourceAdapter` 인터페이스(`available`, `unavailable_reason`, `fetch(since)`)
  - `OfficialKidsnoteAdapter`: 항상 `available=False`. 공식 수단 확보 후 `fetch` 구현 자리
  - `MockAdapter`: JSON 파일을 키즈노트처럼 돌려줌(개발·QA 전용, `--notice-source mock:<파일>`)
  - 동기화 엔진 `run_sync`: 선생님·원 글만(학부모 댓글 제외) → 출처 ID+내용 해시로 신규·수정·중복 판단 → 서버 node 분석기(`dist-server/analyze.mjs`)로 분석 → 저장·파생 항목(준비물·등하원 변경·행사) → 보드 반영
  - 보호자가 고친 공지는 원본이 바뀌어도 덮어쓰지 않고 "원본 바뀜" 기록 + 다시 확인 필요
  - 실패 시 백오프(15분부터 2배, 최대 6시간), 연속 5회 실패면 자동 일시정지(설정에서 다시 켜기), 수동 실행은 1분 간격
  - 예약 실행 `SyncScheduler`: 설정 시각(기본 07:00·11:00·16:00·20:00, 하루 6회 이하), 2시간 넘게 지난 슬롯은 건너뜀
  - node가 없으면 "분석 대기"로 저장 → 보호자 브라우저가 분석해 채움(원문은 분석 후 삭제)
- 설정 화면 "공지 저장·자동 수집": 어댑터 상태·이유, 자동 확인 토글(사용 불가면 비활성), 지금 동기화, 일시정지 해제, 최근 실행 기록
- 계정 보안: 현재 저장하는 키즈노트 인증 정보 없음. 공식 수단이 OAuth/토큰이면 `kma_key.txt`와 같은 방식(데이터 폴더 파일, 권한 600, 로그 금지, 연결 해제 시 삭제)으로 보관하도록 설계
