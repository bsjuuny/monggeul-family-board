## 2. 키즈노트 답변(2026-11-24)과 결정

사용자가 키즈노트에 문의해 받은 답변 요지:

- 외부 서비스 연동용 **공식 API가 없고**, 제휴 신청·개발자 등록 절차도 없다.
- 공지·알림장은 키즈노트 앱·웹에서만 볼 수 있다. 외부 자동 조회, 새 글·수정 확인, 내보내기·공유·알림 연동 기능은 없다.
- **본인 계정이라도 외부 프로그램이 자동으로 접속해 조회·저장하는 방식은 공식 지원 방식이 아니며 권장하지 않는다.** 공지·알림장에 선생님과 다른 원아·보호자 정보가 함께 담길 수 있기 때문. 이 방식으로 생긴 계정 보안 문제·정보 유출은 책임지기 어렵다고 함.
- 안내된 약관: 제6조 2항(아이디·비밀번호를 제3자가 이용하게 하면 안 됨), 제14조(동의 없는 영리 목적 이용 금지), 제16조 3항(공지 저작권은 게시한 이용자), 제16조 6항(알림장은 가족 회원에게 복제 등 권리 부여).

결정(2026-11-24):

- 키즈노트 계정을 보드 서버에 넣어 자동으로 로그인·수집하는 기능은 **만들지 않는다**(약관 제6조 2항, 키즈노트 비권장). 비공식 내부 API 호출 코드도 넣지 않는다.
- 공지·알림장은 보호자가 직접 보고 **붙여넣기** 또는 **공지톡 → 내보내기 → 보드 가져오기**로 넣는다. 기본은 원문 없이 요약만 저장한다.
- 설정 화면에서 쓸 수 없는 자동 수집 칸을 숨기고, 안내 문구를 "키즈노트는 외부 연동을 제공하지 않아 자동으로 가져오지 않아요"로 바꿨다.
- `OfficialKidsnoteAdapter`는 계속 `available=False`. 키즈노트가 공식 수단을 내놓으면 그때 다시 검토한다.

이전 기록(2026-11-20): "키즈노트 문의 후 결정". 그때까지 비공식 호출은 운영 기능으로 켜지 않는다(지시서 7.8).

## 3. 구현한 것(공식 수단이 생기면 바로 연결)

- `tablet_server/kidsnote.py`
  - `NoticeSourceAdapter` 인터페이스(`available`, `unavailable_reason`, `fetch(since)`)
  - `OfficialKidsnoteAdapter`: 항상 `available=False`. 공식 수단 확보 후 `fetch` 구현 자리
  - `MockAdapter`: JSON 파일을 키즈노트처럼 돌려줌(개발·QA 전용, `--notice-source mock:<파일>`)
  - 동기화 엔진 `run_sync`: 선생님·원 글만(학부모 댓글 제외) → 출처 ID+내용 해시로 신규·수정·중복 판단 → 서버 node 분석기(`dist-server/analyze.mjs`)로 분석 → 저장·파생 항목(준비물·등하원 변경·행사) → 보드 반영
  - 보호자가 고친 공지는 원본이 바뀌어도 덮어쓰지 않고 "원본 바뀜" 기록 + 다시 확인 필요
  - 실패 시 백오프(15분부터 2배, 최대 6시간), 연속 5회 실패면 자동 일시정지(설정에서 다시 켜기), 수동 실행은 1분 간격
  - 예약 실행 `SyncScheduler`: 설정 시각(기본 07:00·11:00·16:00·20:00, 하루 6회 이하), 2시간 넘게 지난 슬롯은 건너뜀
  - node가 없으면 "분석 대기"로 저장 → 보호자 브라우저가 분석해 채움(원문은 분석 후 삭제)
- 설정 화면 "공지 저장·자동 수집": 어댑터 상태·이유, 자동 확인 토글(사용 불가면 비활성), 지금 동기화, 일시정지 해제, 최근 실행 기록
- 계정 보안: 현재 저장하는 키즈노트 인증 정보 없음. 공식 수단이 OAuth/토큰이면 `kma_key.txt`와 같은 방식(데이터 폴더 파일, 권한 600, 로그 금지, 연결 해제 시 삭제)으로 보관하도록 설계

## 4. 테스트(모의 연동, `tablet_server/tests/test_v2.py`)

공식 어댑터 비활성(409 SOURCE_NOT_AVAILABLE), 신규 수집·학부모 글 제외, 재수집 중복 없음(준비물 1개 유지), 수정 공지 반영, 보호자 수정 보존, 실패 백오프·일시정지·재개, 수동 실행 간격, 분석기 없음→분석 대기→브라우저 분석, 예약 슬롯 계산 — 모두 통과. **실제 키즈노트 계정 테스트는 하지 않음.**
