범위: v2에서 추가·변경한 서버 API, TV 기기 인증, 공지 저장, 날씨 키, 백업·복원, 프론트 화면. 방법: 코드 검토 + 서버 단위 테스트 72건 + E2E 36건.

## 남은 위험(받아들이거나 나중에)

1. **HTTP 평문(v1부터)**: 같은 Wi-Fi 안에서 트래픽을 볼 수 있다. 공지 요약·아이 이름이 평문으로 오간다. 집 밖 접속이 필요해지면 HTTPS/VPN 구성이 필요하다.
2. **TV 화면 노출**: 기본값은 가리지 않음. 거실 TV에 손님이 많으면 설정 → TV 연결 → 'TV에서 가릴 정보'를 켠다.
3. **페어링 코드 무차별 대입**: 100만 가지·IP당 10회/10분이라 현실적 위험은 낮다. IP를 바꿔 가며 시도하는 공격은 LAN 안 공격자를 전제한다.
4. **분석 대기 원문**: node가 없는 서버는 자동 수집 원문을 분석될 때까지 저장한다(현재 실제 수집은 꺼져 있어 해당 없음).
5. **owner 복원은 강력함**: 백업 파일에 든 v2 표를 백업 시점으로 바꾼다. 복원 직전 DB 파일 전체를 `backups/pre-restore-*`에 자동 저장하므로(11-20 리뷰 반영) 잘못 복원해도 되돌릴 수 있다.
